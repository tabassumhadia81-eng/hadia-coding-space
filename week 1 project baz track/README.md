# BizTrack

BizTrack is a full-stack business management web application developed as a web development practice project.

## Features

* User Signup
* User Login
* User Authentication
* Product Management
* Customer Management
* Sales Management
* Automatic Stock Management
* Expense Management
* Business Reports
* SQLite Database
* REST API
* Password Hashing
* Git & GitHub Integration

## Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* SQLite

### Authentication

* bcryptjs
* JSON Web Token (JWT)

### Version Control

* Git
* GitHub

## Main Modules

### Authentication

Users can create an account and log in securely.

### Products

Users can add, edit, delete and manage products and stock.

### Customers

Users can add and manage customer information.

### Sales

Users can create sales and product stock is automatically updated.

### Expenses

Users can record and manage business expenses.

### Reports

The system provides sales, expenses, profit, products, customers and low-stock information.

## Database

BizTrack uses SQLite to store:

* Users
* Products
* Customers
* Sales
* Expenses

## How to Run

### 1. Install dependencies

```bash
npm install
```

### 2. Start the server

```bash
node server.js
```

### 3. Open the website

Open your browser and visit:

```text
http://localhost:3000
```

## Git & GitHub

Git is used for version control and GitHub is used to store and manage the project source code.

## Project Purpose

This project was created to practice full-stack web development, including frontend development, backend development, database integration, authentication, REST APIs, Git and GitHub.
